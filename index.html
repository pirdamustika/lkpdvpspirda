Fase 1: Pengenalan Konsep VPS & Cloud
Jelaskan secara singkat pemahaman Anda mengenai perbedaan layanan berikut dengan mengisi kotak yang tersedia.
Shared Hosting
Layanan hosting di mana satu server fisik digunakan bersama-sama oleh banyak pengguna. Sumber daya (RAM, CPU, storage) dibagi bersama, harganya terjangkau namun performa bisa terpengaruh jika website lain menggunakan banyak resource.
Dedicated Server
Layanan penyewaan satu server fisik secara utuh khusus untuk satu pengguna saja tanpa dibagi dengan orang lain. Menawarkan performa maksimal, kontrol penuh, dan keamanan tingkat tinggi, namun dengan biaya yang relatif mahal.
Amazon Lightsail
Layanan cloud komputasi dari AWS untuk pemula atau skala kecil-menengah. Menyediakan virtual private server (VPS) dengan harga tetap (flat-rate) yang mencakup penyimpanan, transfer data, dan RAM, sehingga sangat mudah digunakan.
Amazon EC2
Layanan cloud komputasi skala enterprise dari AWS yang menyediakan kapasitas virtual server fleksibel dan dapat diatur sesuai kebutuhan. Sangat skalabel untuk aplikasi besar, namun membutuhkan keahlian teknis lebih tinggi.
